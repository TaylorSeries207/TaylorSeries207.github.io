Python Level 1: Foundations

Module 1: Print

Welcome to Python! The print() function is used to output text or data to the screen.

print("Hello, World!")
print("Welcome to Michael's Coding Class!")

Module 2: Simple Math

Python supports standard arithmetic operations: addition (+), subtraction (-), multiplication (*), and division (/).

a = 10
b = 3
print(a + b)  # Output: 13
print(a * b)  # Output: 30

Module 3: Advanced Math

Learn integer division (//), modulus/remainder (%), and exponentiation (**).

print(10 // 3) # Floor Division -> 3
print(10 % 3)  # Modulus (Remainder) -> 1
print(2 ** 4)  # Exponent -> 16

Module 4: String

Strings store text. You can concatenate strings and use formatted strings (f-strings).

name = "Michael"
print(f"Hello, {name}!")

Module 5: Input and If

Use input() to read user data and if statements to make decisions.

age = int(input("Enter your age: "))
if age >= 18:
    print("Eligible")

Module 6: List

Lists allow storing multiple ordered items in a single variable.

scores = [90, 85, 95]
scores.append(100)
print(scores[0]) # 90

Learn common bugs like SyntaxError, TypeError, and logical errors.
