Module 1: Nested Loops

Concept: In Level 2, we mastered single for and while loops. Now, we step into Level 3: Nested Loops—placing one loop completely inside another! You can nest a for loop inside a for loop, a while inside a while, or even mix both together. This concept is fundamental for 2D grid traversals, brute-force search, and future advanced techniques like Sliding Window algorithms.

1. How Nested Loops Work (Step-by-Step Execution)

Python code executes from top to bottom. When running a nested loop, for every single step of the outer loop, the inner loop completes its ENTIRE execution cycle!

# Nested For Loop Example
for i in range(2):
    for j in range(3):
        print(i, j)
📊 Execution Trace Table (2 × 3 = 6 Total Iterations):
Notice how the outer index i stays fixed while the inner index j runs through all its values:
  • Outer i = 0: Inner j runs 0, 1, 2 → Prints (0, 0), (0, 1), (0, 2)
  • Outer i = 1: Inner j runs 0, 1, 2 → Prints (1, 0), (1, 1), (1, 2)

2. Nested while Loops & The Reset Trap!

You can achieve the exact same nested logic using while loops. However, pay close attention to where the inner loop variable is initialized:

i = 0
while i < 2:
    j = 0  # ⚠️ CRITICAL: Must reset j = 0 inside the outer loop before inner loop starts!
    while j < 3:
        print(i, j)
        j += 1
    i += 1
🚨 The Inner Reset Trap: If you place j = 0 outside the outer loop (above i = 0), the inner loop will only run during the first iteration of i = 0! On subsequent outer loops, j will already equal 3, causing the inner loop to be completely skipped!

3. Practical Example: Printing 2D Shapes & Grids

Nested loops are perfect for constructing multi-row patterns and grid systems using the end="" print parameter:

# Print a 4x5 Star Grid (4 rows, 5 columns)
for row in range(4):
    for col in range(5):
        print("*", end=" ")
    print()  # Print a newline after finishing each row
