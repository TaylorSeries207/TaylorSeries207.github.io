Python Level 1: Foundations

Module 1: Print Function

Concept: The print() function is used to output text or data directly to the screen console.

print("Hello World")
print("Welcome to Michael's Coding Class!")
📌 Important Notice: Your code's execution result will not be visible on the screen unless you explicitly print it out. Don't forget this when testing your logic!

Understanding Escape Characters (\n) & Line Ends

By default, print() automatically ends with a newline character (\n), which explains why consecutive print statements appear on new lines. You can also manually insert \n inside a string:

print("Hello World \nHello World")

We can override the default newline ending by explicitly specifying the end parameter:

print("Hello World", end=" ")
print("Next Line")

Try running this in your IDE to see how the two sentences join onto the same line, then demonstrate it to your instructor!

Module 2: Variables & Basic Math

Concept: Python supports standard arithmetic calculations using +, -, *, and / corresponding to Addition, Subtraction, Multiplication, and Division.

A Variable is a fundamental concept used to store data values in memory. The primary numeric variable types are:

  • int (Integer): Whole numbers without decimal points (e.g., 1, 42, -10).
  • float (Floating-point): Numbers with decimal points (e.g., 9.8, 3.14).
a = 1
b = 2
print(a + b)  # Output: 3

Here, 1 is stored in variable a and 2 is stored in b. If we change the values assigned to a and b, the printed result will update automatically—highlighting why variables are indispensable in programming!

Example: Real-World Word Problem

A class has 33 students in total. If 12 of them are girls, how many boys are there?

cla = 33      # Avoid using 'class' as a variable name since it is a reserved Python keyword
girls = 12
boys = cla - girls  # Use variables instead of hardcoded numbers like 33 - 12
print("There are", boys, "boys")  # Separate strings and variables with commas
💡 Type Rules & Conversions:
  • int + int → int
  • int - int → int
  • int * int → int
  • int / int → float (Division always returns a float!)
  • Any operation involving a float yields a float.
You can inspect a variable's data type anytime using type(f).

Rounding Numbers

To round a float to the nearest integer or specific decimal places, use the built-in round() function:

number = 9.2141241

rounded_num = round(number)
print(rounded_num)     # Output: 9

rounded_num2 = round(number, 2)
print(rounded_num2)    # Output: 9.21

Module 3: Advanced Math & Random Library

Concept: In this module, we introduce advanced arithmetic operators: Floor Division (//), Modulus (%), and Exponentiation (**).

  • Floor Division (//): Discards the fractional remainder and returns only the integer quotient. E.g., print(8 // 3) → 2.
  • Modulus (%): Returns the remainder after division. E.g., print(8 % 5) → 3.
  • Exponentiation (**): Raises a base to a power. E.g., print(2 ** 3) → 8.

Min & Max Functions

The min() and max() functions find the smallest and largest values among passed arguments or collections:

print(min(2, 1, 2, 3, 5))   # Output: 1

biggest = max(1, 2, 3, 4, 5)
print(biggest)              # Output: 5

Extension: The random Library

Python provides a built-in module called random to generate pseudo-random numbers.

import random  # Step 1: Import the module before using it

# Generate a random integer between 1 and 100 (inclusive)
r_int = random.randint(1, 100)

# Generate a random float between 1.0 and 100.0
r_float = random.uniform(1, 100)

# Generate a random float between 0.0 and 1.0
r_zero_one = random.random()

Module 4: String Operations

Concept: Strings are sequences of characters used to store textual data. Key properties to remember:

  • Strings must always be enclosed in quotes (single '...' or double "...").
  • Numbers wrapped in quotes are treated as text: compare print(3 + 4) → 7 vs. print("3+4") → 3+4.

Basic Operations: Length, Concatenation, and Multiplication

s = "HelloWorld!"

print(s)        # Prints the string
print(len(s))   # Output: 11 (counts characters, spaces, and punctuation)

# String Concatenation (Addition)
addition = s + " Good morning"
print(addition) # Output: HelloWorld! Good morning

# String Multiplication
multi = s * 3
print(multi)    # Output: HelloWorld!HelloWorld!HelloWorld!
⚠️ Rule: You cannot subtract (-) or divide (/) strings in Python!

String Indexing & Slicing

Every character in a string has a zero-based index position:

Character MICHAEL
Forward Index 0123456
Reverse Index -7-6-5-4-3-2-1 
s = "HelloWorld!"

print(s[0])     # 'H' (First element)
print(s[-1])    # '!' (Last element)

# Slicing: s[start:end] - Upper bound is EXCLUDED!
print(s[0:3])   # 'Hel' (Indices 0, 1, 2)
print(s[1:])    # 'elloWorld!' (From index 1 to the end)
print(s[:5])    # 'Hello' (From index 0 to 4)
🔒 String Immutability (Important Teaching Concept!):
Suppose you accidentally misspelled "hamburger" as wrong = "hamgurger", and you want to fix the second g at index 3 to a b: 
wrong = "hamgurger"
wrong[3] = "b"  # ❌ TypeError! Strings in Python are immutable and cannot be reassigned directly.
How to correctly fix it? Use string slicing to reassemble the string: 
fixed = wrong[0:3] + "b" + wrong[4:]
print(fixed)    # Output: hamburger

Useful String Methods

s = "HelloWorld!"

print(s.index("W"))   # 5 (Returns the index of the FIRST occurrence of "W")
print(s.count("o"))   # 2 (Counts total occurrences of "o")

print(s.upper())      # "HELLOWORLD!"
print(s.lower())      # "helloworld!"

# Boolean Check Functions (Return True or False)
print(s.isalpha())    # False (because '!' is not a letter)
print(s.isupper())    # False
print(s.islower())    # False
print(s.isdigit())    # False
print(s.isalnum())    # False (because '!' is a special character)

F-String (Formatted String Literals)

F-strings provide a clean, modern way to embed variables directly inside strings without messy comma separation or type casting. Simply prefix the string with an f and put variables inside curly braces {}:

temp = 28.5
wea = "Sunny"

# Clean formatting using f-string
print(f"Today's temperature is {temp}°C, and it's a {wea} day!")
# Output: Today's temperature is 28.5°C, and it's a Sunny day!

Module 5: Input and If Statements

Concept: The input() function allows users to interact with your Python program in real time by entering text from the console. Whatever the user types is returned and stored in a variable.

Reading Inputs & Data Type Conversions

🚨 The Big Input Trap: By default, input() ALWAYS returns data as a String! If you want to do mathematical calculations or numerical comparisons, you MUST explicitly convert (cast) it to an int or float. 
# 1. String Input (Default behavior)
s = input("Please enter something: ")
print(f"You entered string: {s}")

# 2. Integer Input (Cast using int())
int_s = int(input("Please enter an integer: "))
print(f"Your integer times 2: {int_s * 2}")

# 3. Float Input (Cast using float())
float_s = float(input("Please enter a decimal number: "))
print(f"Your float: {float_s}")

Be careful with input types! If you attempt to convert invalid text to a number (e.g., executing int(input()) when the user enters "toxic"), Python will crash with a ValueError. Always read contest problems carefully to know what type of data is being passed in!

Conditional Logic: The if Statement & Booleans

An if statement checks whether a condition evaluates to Boolean values: True or False. If the condition is True, the indented code block executes; if False, Python skips it.

grades = int(input("Enter your grade: "))

# Notice the colon ':' at the end of the line!
if grades >= 90:
    print("Good job!")  # Indented 4 spaces

Comparison Operators

We use comparison operators to compare values in Boolean expressions:

  • == (Equal to) — ⚠️ Do NOT confuse with = which is used to assign values!
  • != (Not equal to)
  • > (Greater than), < (Less than)
  • >= (Greater than or equal to), <= (Less than or equal to)
💡 Chained Comparison Trick: Python allows range comparison syntax like 90 <= grades <= 100 to check if a number falls between two boundaries!

The else Clause & Logical Operators (and / or / not)

The else block covers all remaining cases when the if condition evaluates to False.

age = int(input("Enter your age: "))

if age >= 18:
    print("Adult ticket: $15")
else:
    print("Child ticket: $8")

Nested If Structures

You can nest an if statement inside another if statement to check multiple sequential conditions:

grades = int(input("Enter academic grade: "))
PE_grades = int(input("Enter PE grade: "))

if grades >= 90:
    if PE_grades >= 90:
        print("Perfect! Balanced mind and body.")
    else:
        print("Great academics, now go touch some grass!")
else:
    print("Keep working hard!")
