Python Level 1: Foundations

Module 1: Print Function

Concept: The print() function is used to output text or data directly to the screen console.

print("Hello World")
print("Welcome to Michael's Coding Class!")
📌 Important Notice: Your code's execution result will not be visible on the screen unless you explicitly print it out. Don't forget this when testing your logic!

Understanding Escape Characters (\n) & Line Ends

By default, print() automatically ends with a newline character (\n), which explains why consecutive print statements appear on new lines. You can also manually insert \n inside a string:

print("Hello World \nHello World")

We can override the default newline ending by explicitly specifying the end parameter:

print("Hello World", end=" ")
print("Next Line")

Try running this in your IDE to see how the two sentences join onto the same line, then demonstrate it to your instructor!

Module 2: Variables & Basic Math

Concept: Python supports standard arithmetic calculations using +, -, *, and / corresponding to Addition, Subtraction, Multiplication, and Division.

A Variable is a fundamental concept used to store data values in memory. The primary numeric variable types are:

  • int (Integer): Whole numbers without decimal points (e.g., 1, 42, -10).
  • float (Floating-point): Numbers with decimal points (e.g., 9.8, 3.14).
a = 1
b = 2
print(a + b)  # Output: 3

Here, 1 is stored in variable a and 2 is stored in b. If we change the values assigned to a and b, the printed result will update automatically—highlighting why variables are indispensable in programming!

Example: Real-World Word Problem

A class has 33 students in total. If 12 of them are girls, how many boys are there?

cla = 33      # Avoid using 'class' as a variable name since it is a reserved Python keyword
girls = 12
boys = cla - girls  # Use variables instead of hardcoded numbers like 33 - 12
print("There are", boys, "boys")  # Separate strings and variables with commas
💡 Type Rules & Conversions:
  • int + int → int
  • int - int → int
  • int * int → int
  • int / int → float (Division always returns a float!)
  • Any operation involving a float yields a float.
You can inspect a variable's data type anytime using type(f).

Rounding Numbers

To round a float to the nearest integer or specific decimal places, use the built-in round() function:

number = 9.2141241

rounded_num = round(number)
print(rounded_num)     # Output: 9

rounded_num2 = round(number, 2)
print(rounded_num2)    # Output: 9.21

Module 3: Advanced Math & Random Library

Concept: In this module, we introduce advanced arithmetic operators: Floor Division (//), Modulus (%), and Exponentiation (**).

  • Floor Division (//): Discards the fractional remainder and returns only the integer quotient. E.g., print(8 // 3) → 2.
  • Modulus (%): Returns the remainder after division. E.g., print(8 % 5) → 3.
  • Exponentiation (**): Raises a base to a power. E.g., print(2 ** 3) → 8.

Min & Max Functions

The min() and max() functions find the smallest and largest values among passed arguments or collections:

print(min(2, 1, 2, 3, 5))   # Output: 1

biggest = max(1, 2, 3, 4, 5)
print(biggest)              # Output: 5

Extension: The random Library

Python provides a built-in module called random to generate pseudo-random numbers.

import random  # Step 1: Import the module before using it

# Generate a random integer between 1 and 100 (inclusive)
r_int = random.randint(1, 100)

# Generate a random float between 1.0 and 100.0
r_float = random.uniform(1, 100)

# Generate a random float between 0.0 and 1.0
r_zero_one = random.random()

Module 4: String Operations

Concept: Strings are sequences of characters used to store textual data. Key properties to remember:

  • Strings must always be enclosed in quotes (single '...' or double "...").
  • Numbers wrapped in quotes are treated as text: compare print(3 + 4) → 7 vs. print("3+4") → 3+4.

Basic Operations: Length, Concatenation, and Multiplication

s = "HelloWorld!"

print(s)        # Prints the string
print(len(s))   # Output: 11 (counts characters, spaces, and punctuation)

# String Concatenation (Addition)
addition = s + " Good morning"
print(addition) # Output: HelloWorld! Good morning

# String Multiplication
multi = s * 3
print(multi)    # Output: HelloWorld!HelloWorld!HelloWorld!
⚠️ Rule: You cannot subtract (-) or divide (/) strings in Python!

String Indexing & Slicing

Every character in a string has a zero-based index position:

Character MICHAEL
Forward Index 0123456
Reverse Index -7-6-5-4-3-2-1 
s = "HelloWorld!"

print(s[0])     # 'H' (First element)
print(s[-1])    # '!' (Last element)

# Slicing: s[start:end] - Upper bound is EXCLUDED!
print(s[0:3])   # 'Hel' (Indices 0, 1, 2)
print(s[1:])    # 'elloWorld!' (From index 1 to the end)
print(s[:5])    # 'Hello' (From index 0 to 4)
🔒 String Immutability (Important Teaching Concept!):
Suppose you accidentally misspelled "hamburger" as wrong = "hamgurger", and you want to fix the second g at index 3 to a b: 
wrong = "hamgurger"
wrong[3] = "b"  # ❌ TypeError! Strings in Python are immutable and cannot be reassigned directly.
How to correctly fix it? Use string slicing to reassemble the string: 
fixed = wrong[0:3] + "b" + wrong[4:]
print(fixed)    # Output: hamburger

Useful String Methods

s = "HelloWorld!"

print(s.index("W"))   # 5 (Returns the index of the FIRST occurrence of "W")
print(s.count("o"))   # 2 (Counts total occurrences of "o")

print(s.upper())      # "HELLOWORLD!"
print(s.lower())      # "helloworld!"

# Boolean Check Functions (Return True or False)
print(s.isalpha())    # False (because '!' is not a letter)
print(s.isupper())    # False
print(s.islower())    # False
print(s.isdigit())    # False
print(s.isalnum())    # False (because '!' is a special character)

F-String (Formatted String Literals)

F-strings provide a clean, modern way to embed variables directly inside strings without messy comma separation or type casting. Simply prefix the string with an f and put variables inside curly braces {}:

temp = 28.5
wea = "Sunny"

# Clean formatting using f-string
print(f"Today's temperature is {temp}°C, and it's a {wea} day!")
# Output: Today's temperature is 28.5°C, and it's a Sunny day!

Module 5: Input and If Statements

Concept: The input() function allows users to interact with your Python program in real time by entering text from the console. Whatever the user types is returned and stored in a variable.

Reading Inputs & Data Type Conversions

🚨 The Big Input Trap: By default, input() ALWAYS returns data as a String! If you want to do mathematical calculations or numerical comparisons, you MUST explicitly convert (cast) it to an int or float. 
# 1. String Input (Default behavior)
s = input("Please enter something: ")
print(f"You entered string: {s}")

# 2. Integer Input (Cast using int())
int_s = int(input("Please enter an integer: "))
print(f"Your integer times 2: {int_s * 2}")

# 3. Float Input (Cast using float())
float_s = float(input("Please enter a decimal number: "))
print(f"Your float: {float_s}")

Be careful with input types! If you attempt to convert invalid text to a number (e.g., executing int(input()) when the user enters "toxic"), Python will crash with a ValueError. Always read contest problems carefully to know what type of data is being passed in!

Conditional Logic: The if Statement & Booleans

An if statement checks whether a condition evaluates to Boolean values: True or False. If the condition is True, the indented code block executes; if False, Python skips it.

grades = int(input("Enter your grade: "))

# Notice the colon ':' at the end of the line!
if grades >= 90:
    print("Good job!")  # Indented 4 spaces

Comparison Operators

We use comparison operators to compare values in Boolean expressions:

  • == (Equal to) — ⚠️ Do NOT confuse with = which is used to assign values!
  • != (Not equal to)
  • > (Greater than), < (Less than)
  • >= (Greater than or equal to), <= (Less than or equal to)
💡 Chained Comparison Trick: Python allows range comparison syntax like 90 <= grades <= 100 to check if a number falls between two boundaries!

The else Clause & Logical Operators (and / or / not)

The else block covers all remaining cases when the if condition evaluates to False.

age = int(input("Enter your age: "))

if age >= 18:
    print("Adult ticket: $15")
else:
    print("Child ticket: $8")

Nested If Structures

You can nest an if statement inside another if statement to check multiple sequential conditions:

grades = int(input("Enter academic grade: "))
PE_grades = int(input("Enter PE grade: "))

if grades >= 90:
    if PE_grades >= 90:
        print("Perfect! Balanced mind and body.")
    else:
        print("Great academics, now go touch some grass!")
else:
    print("Keep working hard!")

Module 6: Python Lists (Arrays)

Concept: A List is one of Python's most versatile and powerful data structures. It allows you to store an ordered sequence of multiple items—even of different data types—in a single variable.

# Sample list storing mixed data types
sample_list = [1, "23", 29, [0, 1, 2]]
print(sample_list)  # Output: [1, '23', 29, [0, 1, 2]]

Initializing Lists & Adding Elements

Lists are enclosed in square brackets []. You can start with an empty list or predefined values:

l = []            # Initialize an empty list
l1 = [1, 2, 3]    # Pre-populated list

# .append(x): Adds an element to the VERY BACK (End) of the list
l.append(1)
l.append(3)
l.append(2)
l.append(4)
l.append(5)
print(l)  # Output: [1, 3, 2, 4, 5]

Removing & Modifying Elements

  • .remove(val): Removes the first occurrence of a specified value. Throws an error if the value isn't found.
  • .pop(index): Removes and returns the element at a specific index (defaults to the last item if no index is passed).
  • l[index] = new_val: Replaces the existing element at the given index.
l = [1, 3, 2, 4, 5]

l.remove(5)   # Removes the number 5 -> [1, 3, 2, 4]
l.pop(1)      # Removes element at index 1 (the number 3) -> [1, 2, 4]
l[1] = 99     # Updates index 1 to 99 -> [1, 99, 4]

print(l)      # Output: [1, 99, 4]
⚠️ Performance Tip (Important for CCC!):
Inserting (l.insert(index, val)) or Removing (l.remove(val)) at the beginning/middle of a list can be slow ($O(N)$ time). Think of a list as a line of people: if someone steps out from the middle, everyone behind them must shift forward one by one!

Indexing, Slicing & Searching

Just like strings, list indexing starts at 0, and slicing upper bounds are excluded:

l = [10, 20, 30, 40, 50]

print(l[0])       # 10 (First item)
print(l[-1])      # 50 (Last item)
print(l[1:4])     # [20, 30, 40] (Sublist from index 1 to 3)
print(len(l))     # 5 (Total count of elements)

# Membership checks & Search
print(20 in l)         # True (Checks if element exists)
print(l.index(30))     # 2 (Returns index of first occurrence)
print(min(l), max(l))  # 10 50 (Finds minimum and maximum values)
print(sum(l))          # 150 (Calculates the sum of all elements)

Sorting, Reversing & Multiplication

numbers = [5, 2, 8, 1, 9]

numbers.sort()      # Sorts list in ascending order in-place
print(numbers)      # Output: [1, 2, 5, 8, 9]

numbers.reverse()   # Reverses list elements in-place
print(numbers)      # Output: [9, 8, 5, 2, 1]

# Fast Pre-allocation: Creates a list with eight zeros
zeros = [0] * 8
print(zeros)        # Output: [0, 0, 0, 0, 0, 0, 0, 0]

Reading Contest Inputs into Lists: input().split() & map()

In competitive programming (DMOJ/CCC), input lines often contain multiple space-separated numbers (e.g., "8 9 1 2 1").

# 1. Reading two fixed variables on one line
a, b = input().split()  # Returns strings. Convert using int(a), int(b)

# 2. Converting an entire input line directly into an Integer List!
# map(int, ...) applies int() conversion to every element in the split input
l_int = list(map(int, input().split()))
print(l_int)  # e.g., Input: "8 9 1 2 1" -> Output: [8, 9, 1, 2, 1]

Unpacking & Formatting Output: The Star Operator (*)

To print list elements separated by spaces without square brackets or commas, use the unpacking operator *:

l = [1, 2, 3, 4, 5]

print(l)               # [1, 2, 3, 4, 5] (Default representation)
print(*l)              # 1 2 3 4 5 (Unpacked with default spaces)
print(*l, sep=", ")    # 1, 2, 3, 4, 5 (Custom separator)

Python Level 2: Control & Loops

Module 1: Elif Statement & Logical Operators

Concept: In Level 1, we learned how basic if and else statements work. As programs grow more complex, checking multiple mutual conditions using just if and else becomes messy. That's where the elif (short for else if) statement comes in!

The Structure of if-elif-else

An elif statement MUST follow an initial if statement and appear BEFORE the final else block. You can chain as many elif blocks as you need between them:

grades = int(input("Enter your score: "))

if grades > 100:
    print("Invalid input!")
elif grades >= 90:
    print("Grade: A")
elif grades >= 80:
    print("Grade: B")
elif grades >= 70:
    print("Grade: C")
elif grades >= 60:
    print("Grade: D")
else:
    print("Fail - Keep working hard!")
💡 Logic Flow: Top-to-Bottom Execution
An elif block evaluates if and only if the preceding if or elif conditions evaluated to False. Once Python finds a condition that evaluates to True, it executes that block and skips all remaining elif / else blocks!

Logical Operators: and vs. or

When forming complex conditions, we combine Boolean expressions using and and or:

  • and: ALL conditions must be True for the entire expression to be True.
  • or: If AT LEAST ONE condition is True, the entire expression becomes True.
🍉 The Superstore Watermelon Analogy:
Imagine you are buying watermelons at Superstore:
  • and (The Combo Deal): You are buying a combo package of 2 watermelons. If even ONE watermelon is rotten, you are unhappy (False). Both watermelons MUST be good for you to be happy (True)!
  • or (Individual Selection): You need to buy just 1 good watermelon out of a pile of 2. If ANY of them is good, you are happy (True)! You are only unhappy (False) if both are completely bad.

Chaining Boundaries in Python vs. and

In Python, you can write clean boundary checks using either explicit and operators or chained inequality expressions:

score = int(input("Enter score: "))

# Approach 1: Using 'and'
if score >= 90 and score <= 100:
    print("Grade A")

# Approach 2: Pythonic Chained Range (Shorter & Cleaner!)
if 90 <= score <= 100:
    print("Grade A")

Module 3: While Loop & Counter Pattern

Concept: A loop is one of the most fundamental concepts in programming. It allows you to automate repetition and run a block of code multiple times without rewriting it.

1. Basic while Loop Structure

A while loop continuously executes code as long as its condition remains True:

i = 0
while i < 100:
    print(i)
    i = i + 1   # Can also be written using the shortcut: i += 1
🚨 The Infinite Loop Trap!
Don't forget to update your loop variable (e.g., i += 1)! If you forget to increment i, the condition i < 100 will stay True forever, resulting in a program freeze known as an Infinite Loop.

2. The while True Pattern with break

Instead of placing a condition at the start, you can write an intentionally infinite loop while True and use a break statement inside an if check to exit when a specific condition is met:

i = 0
while True:
    if i == 99:
        break   # Exit the loop immediately
    print(i)
    i += 1
💡 Rule: When using while True, ALWAYS make sure you have a valid break condition to safely exit the loop!

3. The Counter Pattern

A Counter is not a specific keyword or built-in function in Python—it is a core programming design pattern! We initialize a variable to 0 before the loop and increment it (counter += 1) whenever a target item is found as we iterate using a while loop.

s = "aasgasgsaagfdsaga"
i = 0
counter = 0

while i < len(s):
    if s[i] == "a":
        counter += 1
    i += 1

print(f"Total count of 'a': {counter}")

Module 4: For Loop & Range Function

Concept: Compared to while loops, for loops provide a much cleaner and easier syntax when you know in advance how many times you need to repeat a block of code.

1. The Anatomy of range(start, end, step)

The range() function generates a sequence of numbers. Its formal structure is range(start, end, step):

  • start: The starting integer (inclusive). Default is 0 if omitted.
  • end: The upper boundary (EXCLUDED - the loop stops right before this number!).
  • step: How much the loop variable increments each step (similar to i += step in a while loop). Default is 1 if omitted.
# 1. Single argument: range(end) -> starts at 0, steps by 1
for i in range(5):
    print(i)  # Outputs: 0, 1, 2, 3, 4

# 2. Two arguments: range(start, end) -> steps by 1
for i in range(1, 5):
    print(i)  # Outputs: 1, 2, 3, 4

# 3. Three arguments: range(start, end, step)
for i in range(0, 10, 2):
    print(i)  # Outputs: 0, 2, 4, 6, 8
💡 CCC Contest Pattern — Handling $N$ Lines of Input:
In CCC problems, you are often given a number $N$ followed by $N$ separate inputs. A for loop is the ideal tool for this pattern: 
n = int(input("How many numbers? "))
l = []

for i in range(n):
    x = int(input())
    l.append(x)

2. Directly Iterating Over Strings & Lists

Python allows you to loop directly through sequence elements (iterables) using for element in sequence: without needing manual index tracking!

s = "abcde"

# Elegant shortcut for iterating over characters
for char in s:
    print(char)  # Prints each character on a new line

Module 6: Hashset (Sets in Python)

Concept: A Set (often called a Hashset in computer science) is a built-in Python data structure designed for storing unique items and performing lightning-fast membership checks.

1. Automatic Deduplication (Removing Duplicates)

In Level 1, if we wanted to remove duplicate items from a list, we had to write a manual for loop with an if x not in ls: check:

# Old Manual Way (Slower & Wordy)
l = [1, 1, 2, 1, 12, 31, 1]
ls = []
for x in l:
    if x not in ls:
        ls.append(x)
print(ls)  # [1, 2, 12, 31]

With a Set, Python handles deduplication automatically in one single line:

# The Pythonic Set Way (Fast & Clean!)
l = [1, 1, 2, 1, 12, 31, 1]
ls = list(set(l))  # Convert list -> set (deduplicate) -> list
print(ls)  # [1, 2, 12, 31]

2. The 3 Core Properties of Sets

  • No Duplicates: A set can never contain duplicate elements. Adding an existing item does nothing.
  • $O(1)$ Ultra-Fast Search Speed: Checking if x in my_set takes constant time ($O(1)$), regardless of whether the set has 10 items or 10,000,000 items!
  • Unordered & Unindexed: Sets do not keep items in any specific positional sequence. Therefore, you CANNOT use index brackets like my_set[0] (this will trigger a TypeError).
🏫 The School Sign-In Sheet Analogy (List vs. Set Lookup):
Imagine searching for a friend at school:
  • List (x in my_list): Like walking classroom by classroom, checking every student one by one until you find your friend. If there are 1,000 classrooms, it takes a long time! ($O(N)$ time complexity)
  • Set (x in my_set): Like looking at the front desk's Master Sign-In Sheet. You look up their name instantly to confirm whether they are in school today! ($O(1)$ time complexity)

3. Common Set Operations

# 1. Creating an empty set (Must use set(), NOT {} which creates a dictionary!)
s = set()

# 2. Adding elements (.add)
s.add(10)
s.add(20)
s.add(10)  # Duplicate 10 is automatically ignored!

# 3. Removing elements (.remove)
s.remove(20)

# 4. Fast Membership Check
if 10 in s:
    print("10 exists in the set!")

# 5. Convert back to List if indexing/sorting is needed
sorted_unique_list = sorted(list(s))

Module 1: Nested Loops

Concept: In Level 2, we mastered single for and while loops. Now, we step into Level 3: Nested Loops—placing one loop completely inside another! You can nest a for loop inside a for loop, a while inside a while, or even mix both together. This concept is fundamental for 2D grid traversals, brute-force search, and future advanced techniques like Sliding Window algorithms.

1. How Nested Loops Work (Step-by-Step Execution)

Python code executes from top to bottom. When running a nested loop, for every single step of the outer loop, the inner loop completes its ENTIRE execution cycle!

# Nested For Loop Example
for i in range(2):
    for j in range(3):
        print(i, j)
📊 Execution Trace Table (2 × 3 = 6 Total Iterations):
Notice how the outer index i stays fixed while the inner index j runs through all its values:
  • Outer i = 0: Inner j runs 0, 1, 2 → Prints (0, 0), (0, 1), (0, 2)
  • Outer i = 1: Inner j runs 0, 1, 2 → Prints (1, 0), (1, 1), (1, 2)

2. Nested while Loops & The Reset Trap!

You can achieve the exact same nested logic using while loops. However, pay close attention to where the inner loop variable is initialized:

i = 0
while i < 2:
    j = 0  # ⚠️ CRITICAL: Must reset j = 0 inside the outer loop before inner loop starts!
    while j < 3:
        print(i, j)
        j += 1
    i += 1
🚨 The Inner Reset Trap: If you place j = 0 outside the outer loop (above i = 0), the inner loop will only run during the first iteration of i = 0! On subsequent outer loops, j will already equal 3, causing the inner loop to be completely skipped!

3. Practical Example: Printing 2D Shapes & Grids

Nested loops are perfect for constructing multi-row patterns and grid systems using the end="" print parameter:

# Print a 4x5 Star Grid (4 rows, 5 columns)
for row in range(4):
    for col in range(5):
        print("*", end=" ")
    print()  # Print a newline after finishing each row

Module 3: Hashmap (Dictionaries in Python)

Concept: In Level 1, we learned that elements in a list are bound to numeric indices (e.g., l[0], l[1]). However, positional indices aren't always ideal for representing paired real-world data. A Hashmap (known as a dict or Dictionary in Python) solves this by mapping custom Keys to Values.

1. Key-Value Structure & Syntax

A dictionary is enclosed in curly brackets {} with entries written as key: value:

# Grade table dictionary mapping Student Name (Key) -> Score (Value)
grades = {
    "Alice": 80,
    "Bob": 90,
    "Charlie": 75
}

# Accessing a value using its key
print(grades["Alice"])  # Output: 80
⚠️ Crucial Rules for Keys & Values:
  • Keys MUST be Unique: Duplicate keys are NOT allowed. Re-assigning an existing key will overwrite its old value.
  • Values CAN be Duplicated: Multiple different keys can map to the exact same value.
  • Strict Data Types: Be careful with key data types! Key 1 (integer) and key "1" (string) are completely different keys.

2. Basic Dictionary Operations

# 1. Initialize an empty dictionary
hm = {}

# 2. Add or Update Key-Value pairs
hm["A"] = 100       # Adds "A": 100
hm["B"] = 200       # Adds "B": 200
hm["A"] = 999       # Updates "A" to 999

# 3. Remove a Key-Value pair using del
del hm["B"]

# 4. Fast O(1) Key Membership Check
if "A" in hm:
    print("'A' exists in the dictionary!")

# 5. Iterating through a dictionary
for key in hm:
    print(key, hm[key])

# 6. Converting Keys, Values, and Items to Lists
key_list = list(hm.keys())     # e.g., ['A']
value_list = list(hm.values()) # e.g., [999]
item_tuples = list(hm.items()) # e.g., [('A', 999)]
⚡ No Positional Indices (Hash Property):
Like Hashsets, Hashmaps rely on hashing algorithms for instant $O(1)$ speed. They do NOT have index positions. Executing hm[0] will NOT access the first element—it will search for a key named 0!

3. Core Design Pattern: Frequency Table

One of the most important applications of Hashmaps in competitive programming is building a Frequency Table to count occurrences of items (characters, numbers, or words):

s = "12112311231231"
freq = {}

for char in s:
    if char in freq:
        freq[char] += 1
    else:
        freq[char] = 1

print(freq)  # Output: {'1': 7, '2': 4, '3': 3}

# Pythonic Shortcut using .get(key, default_value):
# freq[char] = freq.get(char, 0) + 1

Module 4: 2D Arrays (Matrices in Python)

Concept: In Python, a 2D Array (or Matrix) is implemented as a List of Sublists. Think of it as a table or grid with Rows and Columns. To access any individual element, you must specify two indices: grid[row_index][col_index].

1. Understanding Row & Column Indexing

Consider the following 3x3 matrix initialized as a list of lists:

grid = [
    [1, 2, 3],  # Row 0
    [4, 5, 6],  # Row 1
    [7, 8, 9]   # Row 2
]

Visualization of coordinates in zero-based indexing:

Col 0 Col 1 Col 2
Row 0 grid[0][0] → 1 grid[0][1] → 2 grid[0][2] → 3
Row 1 grid[1][0] → 4 grid[1][1] → 5 grid[1][2] → 6
Row 2 grid[2][0] → 7 grid[2][1] → 8 (Row 2, Col 1) grid[2][2] → 9
🚨 THE BIG TRAP: How to Properly Initialize a 2D Array!
NEVER initialize a 2D grid like this: 
# ❌ WRONG! Creates shallow copies sharing the exact same memory address!
grid = [[0] * 3] * 3 
grid[0][0] = 99  # Modifying row 0 will accidentally change grid[1][0] and grid[2][0] too!
ALWAYS use List Comprehension to build safe 2D grids: 
# ✅ CORRECT! Creates independent row lists in memory
rows = 3
cols = 4
grid = [[0] * cols for _ in range(rows)]
grid[0][0] = 99  # Safe! Only updates Row 0, Col 0.

2. Two Ways to Loop Through a 2D Array

Approach A: Direct Element Iteration (For Pure Reading)

for row in grid:
    for item in row:
        print(item, end=" ")
    print()  # Newline after each row

Approach B: Index-Based Traversal (Required for Modifying or Checking Neighbors)

rows = len(grid)
cols = len(grid[0])

for r in range(rows):
    for c in range(cols):
        print(f"Element at ({r}, {c}) is {grid[r][c]}")

Module 5: Prefix Sum & Difference Array

Concept: As we move into advanced algorithms, we encounter problems where basic nested loops become too slow and result in Time Limit Exceeded (TLE). In this module, we introduce two $O(1)$ range query optimization techniques: Prefix Sum (for fast range sum queries) and Difference Array (for fast range updates).

1. Prefix Sum (Fast Range Sum Queries in $O(1)$)

Imagine you have an array arr = [1, 2, 3, 4, 5]. If you are asked to sum the range from index 0 to 3 repeatedly, summing with a loop takes $O(N)$ time. With a Prefix Sum Array, we precalculate cumulative totals so any range sum takes only $O(1)$ time!

💡 Rule: Always start a Prefix Sum Array with an initial 0!
Original array arr = [1, 2, 3, 4, 5] → Prefix array prefix = [0, 1, 3, 6, 10, 15].
To calculate the sum from index L to R (0-indexed inclusive), use the formula:
Range Sum(L..R) = prefix[R + 1] - prefix[L] 
# Standard Prefix Sum Implementation
arr = [1, 2, 3, 4, 5]
n = len(arr)

# 1. Initialize prefix array with a leading 0
prefix = [0] * (n + 1)
for i in range(n):
    prefix[i + 1] = prefix[i] + arr[i]

# Example: Sum from index 0 to 3 (values: 1 + 2 + 3 + 4 = 10)
L, R = 0, 3
ans = prefix[R + 1] - prefix[L]
print(f"Sum from index {L} to {R}: {ans}")  # Output: 10

2. Difference Array (Fast Range Updates in $O(1)$)

What if a problem requires adding a constant value k to a contiguous range [L, R] thousands of times? Updating each element with a loop takes $O(N)$ time per update. A Difference Array allows us to perform range updates in $O(1)$ time by marking boundary changes!

⚡ Difference Array Range Update Algorithm:
  1. To add val to range [L, R]: Add +val to diff[L], and subtract -val from diff[R + 1] (if R + 1 is within bounds).
  2. After all updates are recorded, compute the Prefix Sum of the Difference Array to reconstruct the final values!
# Standard Difference Array Implementation
n = 5
diff = [0] * (n + 1)  # Extra space for R + 1 boundary offset

# Update 1: Add +10 to range [1, 3] (inclusive)
L, R, val = 1, 3, 10
diff[L] += val
if R + 1 < len(diff):
    diff[R + 1] -= val

# Reconstruct final array using Prefix Sum
final_arr = [0] * n
current = 0
for i in range(n):
    current += diff[i]
    final_arr[i] = current

print("Final array after update:", final_arr)  # Output: [0, 10, 10, 10, 0]
🐍 LeetCode vs. DMOJ Hint — Functions & Return Statements:
When solving LeetCode problems, you write code inside a class method function. Using print() will NOT pass the tests—you must use the return statement! Once Python executes a return line, the function immediately stops and yields the output. 
def solution(bookings, n):
    # Your algorithm logic here...
    return result_list  # Function finishes and returns final answer

Module 6: Dynamic Programming (DP)

Concept: Dynamic Programming (DP) is one of the most powerful algorithmic techniques in competitive programming. Instead of recomputing subproblems repeatedly, DP stores solutions to subproblems in a table (memory) and reuses them as we build up to the final answer. "Dynamic" means we continuously update and record states as we move forward!

1. The 4 Steps to Solve Any DP Problem

🧠 The Standard DP Framework:
  1. Define State: What does dp[i] (or dp[r][c]) represent?
  2. Base Cases: Set up the initial known values (e.g., dp[0] = 1).
  3. State Transition Equation: How do previous states combine to form dp[i]?
  4. Computation Order: Run loops forward (or backward) to fill the DP array.

2. 1D DP Fundamentals (Climbing Stairs Pattern)

Let's analyze LeetCode 70 - Climbing Stairs. You can climb 1 or 2 steps at a time. To reach stair 5, you MUST have jumped either from stair 4 (1 step) or stair 3 (2 steps). Therefore, total ways to stair 5 = dp[4] + dp[3]!

State Transition Equation: dp[i] = dp[i-1] + dp[i-2]

class Solution:
    def climbStairs(self, n: int) -> int:
        # Step 1: Initialize DP array of size n + 1 to match 1-based stair indices
        dp = [0] * (n + 1)
        
        # Step 2: Base Cases
        dp[0] = 1  # 1 way to be at ground level
        dp[1] = 1  # 1 way to reach stair 1
        
        # Step 3 & 4: Transition & Loop Fill
        for i in range(2, n + 1):
            dp[i] = dp[i-1] + dp[i-2]
            
        return dp[n]

Module 7: BFS (Breadth-First Search)

Concept: Breadth-First Search (BFS) is a graph traversal algorithm that explores nodes layer-by-layer, expanding outward in concentric circles (like ripples in water). Because BFS visits all positions at distance $D$ before moving to distance $D+1$, it is guaranteed to find the shortest path in unweighted grids or graphs!

1. Queue Data Structure: collections.deque

BFS requires a First-In, First-Out (FIFO) Queue. In Python, always use deque (Double-Ended Queue) from the collections module because popleft() runs in ultra-fast $O(1)$ time (unlike standard list pop(0) which takes slow $O(N)$ time)!

💡 Essential deque Operations:
  • from collections import deque
  • q = deque() → Initialize empty queue
  • q.append((r, c)) → Push new coordinate into queue
  • r, c = q.popleft() → Pop oldest coordinate from front of queue
  • while q: → Loop until the queue is completely empty

2. Standard BFS Template (Formula Code)

Study and memorize this universal formula code for 2D Grid BFS traversals:

from collections import deque

def bfs_grid_template(grid, start_r, start_c):
    rows, cols = len(grid), len(grid[0])
    
    # 1. Initialize Queue and Visited Set
    q = deque([(start_r, start_c, 0)])  # (row, col, distance/steps)
    visited = set([(start_r, start_c)])
    
    # 2. Define 4-Direction Movement Offsets (Up, Down, Left, Right)
    directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
    
    # 3. Layer-by-Layer Queue Loop
    while q:
        r, c, dist = q.popleft()
        
        # Target check (e.g., reached destination)
        if r == rows - 1 and c == cols - 1:
            return dist
            
        # Explore all 4 adjacent neighbors
        for dr, dc in directions:
            nr, nc = r + dr, c + dc
            
            # Boundary & Validity Check
            if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] != 1:
                if (nr, nc) not in visited:
                    visited.add((nr, nc))  # Mark as visited IMMEDIATELY!
                    q.append((nr, nc, dist + 1))
                    
    return -1  # Path not found

Module 8: Recursion, DFS & Backtracking

Concept: Depth-First Search (DFS) explores a graph by going as deep as possible down a single path before backtracking to explore alternate branches. DFS is naturally implemented using Recursion (a function calling itself).

1. Understanding Recursion First

A recursive function breaks a problem down into smaller self-similar instances. Every recursive function MUST contain two parts:

  • Base Case: The stopping condition that terminates recursion.
  • Recursive Call: Calling the function itself with modified arguments moving toward the base case.
# Simple Recursion Example: Factorial Calculation n! = n * (n - 1)!
def factorial(n):
    # 1. Base Case
    if n == 1 or n == 0:
        return 1
    # 2. Recursive Step
    return n * factorial(n - 1)

print(factorial(5))  # Output: 120 (5 * 4 * 3 * 2 * 1)

2. Standard DFS Grid Template (Formula Code)

Below is the standard recursive DFS formula code for grid exploration (e.g., Flood Fill / Connected Components):

def dfs_grid(r, c, grid, visited):
    rows, cols = len(grid), len(grid[0])
    
    # 1. Base Case & Boundary Validation Check
    if r < 0 or r >= rows or c < 0 or c >= cols:
        return
    if grid[r][c] == 1 or (r, c) in visited:  # Wall or already visited
        return
        
    # 2. Mark current cell as visited
    visited.add((r, c))
    
    # 3. Recursively explore all 4 directions (Deep Exploration!)
    dfs_grid(r - 1, c, grid, visited)  # Up
    dfs_grid(r + 1, c, grid, visited)  # Down
    dfs_grid(r, c - 1, grid, visited)  # Left
    dfs_grid(r, c + 1, grid, visited)  # Right

3. Backtracking: Restoring State for Path Searching

While standard DFS marks cells as permanently visited, Backtracking is used when searching for specific valid paths. After exploring a path recursively, we undo/restore the cell's state (unvisit it) so other paths can reuse that same cell!

🔄 The Backtracking Pattern:
# Mark state (Choose)
visited.add((r, c))

# Explore deeper recursively (Explore)
dfs(r, c)

# UNDO state after recursive call finishes! (Unchoose / Backtrack)
visited.remove((r, c))
