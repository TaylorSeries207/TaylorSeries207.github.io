Java Level 1: Foundations

Module 1: Main Method & Output

Concept: Welcome to Java! If you are transitioning from Python, the first thing you will notice is that Java requires more structure. In Python, a single line like print("Hello") works instantly. In Java, however, every line of executable code must live inside a Class, and execution always begins at one exact entry point: the main method.

1. Deconstructing the Java Boilerplate

Let's break down every single keyword in your very first Java program so it never feels like magic again:

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
        System.out.print("Welcome to Java Coding ");
        System.out.println("Class!");
    }
}
  • public class Main: Declares a public container named Main. In Java, the file name MUST match the class name exactly (e.g., Main.java). On competitive programming platforms like DMOJ or CCC, your submission class MUST be named Main.
  • public: Means this method can be accessed from outside the file (by the Java Virtual Machine).
  • static: Means this method belongs to the class itself—it can run immediately without needing to create an object first.
  • void: Indicates that this function performs an action but returns no final value back.
  • main(String[] args): The standardized function name that Java looks for to start your program. String[] args accepts optional command-line text inputs.

2. Printing Text: println vs print

Java provides two primary methods to output text to the screen:

  • System.out.println(): Prints the given text and then automatically jumps to a new line.
  • System.out.print(): Prints the text but keeps the cursor on the same line.
📌 Escape Characters in Strings:
Use \n inside a string to manually insert a line break, and \t for a tab space.
System.out.println("Line 1\nLine 2"); → Prints two separate lines!

Module 2: Primitive Types & Arithmetic Operations

Concept: Static Typing vs. Dynamic Typing. Python is dynamically typed (a variable can hold an integer, and later be assigned a text string). Java is statically typed: you MUST explicitly declare the type of a variable before assigning a value to it. This allows Java to catch bugs during compilation before the program even runs!

1. Java's Core Primitive Data Types

Java stores simple raw values using Primitive Types:

Data Type Description Memory Size Example
int Standard whole numbers ($-2 \times 10^9$ to $+2 \times 10^9$) 32-bit int age = 15;
long Huge whole numbers (Up to $9 \times 10^{18}$). Crucial for CCC! 64-bit long population = 8000000000L;
double Decimal floating-point numbers 64-bit double pi = 3.14159;
boolean Logical truth values (true or false only) 1-bit boolean isPassed = true;
char A single character enclosed in single quotes 16-bit char grade = 'A';

2. The Integer Division Trap & Type Casting

Pay close attention when dividing numbers in Java! Dividing two integers results in Integer Division, which truncates (cuts off) all decimal places completely!

public class Main {
    public static void main(String[] args) {
        int a = 10;
        int b = 3;
        
        // 🚨 INTEGER DIVISION TRAP!
        System.out.println(a / b);           // Output: 3 (Decimals are lost!)
        
        // ✅ FIX: Explicit Type Casting to double forces decimal division
        System.out.println((double)a / b);    // Output: 3.3333333333333335
        
        // MODULUS (Modulo): Remainder of integer division
        System.out.println(a % b);           // Output: 1 (10 divided by 3 has remainder 1)
    }
}
💡 Math Library Helpers:
Java provides built-in math functions inside the Math class:
• Math.max(x, y) & Math.min(x, y) → Returns largest / smallest value.
• Math.abs(x) → Returns absolute value $|x|$.
• Math.pow(base, exp) → Calculates power (e.g., $2^3 = 8.0$, returns double).
• Math.round(x) → Rounds a float/double to the nearest integer.

Module 3: String Operations & The Immutability Rule

Concept: Objects vs. Primitives. Unlike int or char, a String in Java is an Object (a reference type). Strings represent sequences of text enclosed in double quotes (e.g., "Hello").

1. Essential String Manipulation Methods

Because Strings are objects, we interact with them by calling built-in methods:

String msg = "Hello Java!";

// 1. Length of String (Notice: .length() is a METHOD with parentheses!)
System.out.println(msg.length());         // Output: 11

// 2. Access character at index (Zero-based indexing!)
System.out.println(msg.charAt(0));        // Output: 'H'
System.out.println(msg.charAt(6));        // Output: 'J'

// 3. Substring extraction: .substring(startIndex, endIndex)
// CRITICAL: startIndex is INCLUSIVE, endIndex is EXCLUSIVE!
System.out.println(msg.substring(0, 5));  // Output: "Hello" (Indices 0, 1, 2, 3, 4)

// 4. Case Conversion
System.out.println(msg.toUpperCase());    // Output: "HELLO JAVA!"
System.out.println(msg.toLowerCase());    // Output: "hello java!"
🚨 THE BIG TRAP: Comparing Strings in Java!
NEVER use == to compare String contents in Java!
In Java, == checks if two variables point to the exact same memory address location, NOT whether their text contents match!
ALWAYS use .equals() or .equalsIgnoreCase()! 
String s1 = new String("cat");
String s2 = "cat";

System.out.println(s1 == s2);        // ❌ false! (Different memory references)
System.out.println(s1.equals(s2));   // ✅ true! (Compares character by character content)

Module 4: Scanner Input & Conditional Logic

Concept: Interactive programs need to take input from users or contest test files. In Java, we use the Scanner class from java.util.Scanner to read data from System.in.

1. Reading Console Input with Scanner

import java.util.Scanner;  // Import Scanner tool

public class Main {
    public static void main(String[] args) {
        // Create Scanner object reading from standard input
        Scanner sc = new Scanner(System.in);
        
        System.out.print("Enter your exam score: ");
        int score = sc.nextInt();  // Reads the next integer
        
        // Multi-Branch If - Else If - Else Logic
        if (score >= 90) {
            System.out.println("Grade: A+");
        } else if (score >= 80) {
            System.out.println("Grade: A");
        } else if (score >= 50) {
            System.out.println("Grade: Pass");
        } else {
            System.out.println("Needs Review!");
        }
        
        sc.close();  // Good practice: close Scanner when done
    }
}
⚠️ The Dreaded Scanner Trailing Newline Bug!
When you call sc.nextInt() or sc.nextDouble(), Scanner reads the number but leaves the trailing \n (Enter key press) sitting in the input buffer!
If you call sc.nextLine() immediately afterward to read a text line, it will consume that leftover \n instantly and return an empty string!
Fix: Insert a dummy sc.nextLine(); right after reading numbers to flush the newline out of the buffer!

Module 5: Fixed Arrays (int[])

Concept: Fixed Memory Allocation. An array in Java is a contiguous block of memory designed to store multiple items of the same data type. Unlike Python lists, standard Java arrays have a FIXED length created at initialization that can never shrink or grow.

1. Initializing and Indexing Arrays

import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        // Method 1: Declare array with fixed size 5 (Default values populated as 0)
        int[] scores = new int[5];
        scores[0] = 95;  // Index 0: First element
        scores[1] = 88;  // Index 1: Second element
        
        // Array Length Property (Notice: .length has NO parentheses for arrays!)
        System.out.println("Array Capacity: " + scores.length);  // Output: 5
        
        // Method 2: Literal Allocation (Directly assigning values)
        int[] nums = {45, 12, 89, 3, 27};
        
        // Built-in Sorting: Arrays.sort() sorts the array in-place in O(N log N) time!
        Arrays.sort(nums);
        
        // Utility Printing: Arrays.toString() turns array into a readable string
        System.out.println(Arrays.toString(nums));  // Output: [3, 12, 27, 45, 89]
    }
}

Module 6: Methods & Variable Scope

Concept: Modular Code. A method (or function) is a reusable block of code that performs a specific task. Writing methods keeps your code clean, readable, and DRY (Don't Repeat Yourself).

1. Structure of a Static Method

In competitive Java programming, since our main entry point is public static void main, any helper method declared in the same file and called directly from main MUST also be marked with static:

public class Main {
    
    // Custom static method: Accepts two int parameters, returns an int
    public static int calculateArea(int width, int height) {
        int area = width * height;
        return area;  // Returns calculated result
    }

    public static void main(String[] args) {
        // Call helper method
        int result = calculateArea(10, 20);
        System.out.println("Rectangle Area: " + result);  // Output: 200
    }
}
🔒 Variable Scope & Pass-by-Value:
Variables declared inside a method exist ONLY within that method's curly braces {}.
Java passes primitive arguments by value—modifying a parameter variable inside a helper method will NOT change the original variable back in main()!

Module 7: Debugging & NullPointerException (NPE)

Concept: Understanding Null. In Java, primitive variables (like int) directly store values (defaulting to 0). Object reference variables (like String or arrays) store memory reference pointers. If an object reference variable points to no memory location, its value is null.

Attempting to call a method or property on a variable that holds null causes Java to crash with a NullPointerException (NPE)!

public class Main {
    public static void main(String[] args) {
        String username = null;
        
        // ❌ CRASH! Throws NullPointerException because username has no object!
        // System.out.println(username.length());
        
        // ✅ SAFE GUARD: Always check if object is null first!
        if (username != null && username.length() > 0) {
            System.out.println("User length: " + username.length());
        } else {
            System.out.println("Username is null or uninitialized!");
        }
    }
}

Module 1: Switch Statements & Ternary Operator

Concept: Cleaning Up Conditional Code. When matching a single variable against multiple discrete options, writing dozens of else if branches becomes messy. Java provides switch statements and concise inline ternary operators to streamline your code.

1. Modern Switch Expressions & Ternary Syntax

int option = 2;

// Modern Java Switch Expression (Arrow Syntax - Prevents accidental fall-through!)
switch (option) {
    case 1 -> System.out.println("Option 1 Selected");
    case 2 -> System.out.println("Option 2 Selected");
    case 3 -> System.out.println("Option 3 Selected");
    default -> System.out.println("Invalid Choice");
}

// Ternary Operator Short-hand: (condition) ? valueIfTrue : valueIfFalse;
int mark = 85;
String result = (mark >= 50) ? "PASS" : "FAIL";
System.out.println("Status: " + result);  // Output: Status: PASS

Module 3: While & Do-While Loops

Concept: Indefinite Iteration. Use a while loop when you do not know in advance how many times an operation needs to run. A do-while loop guarantees that the code block executes at least once before checking its continuation condition.

// Standard While Loop
int energy = 100;
while (energy > 0) {
    System.out.println("Running... Energy left: " + energy);
    energy -= 30;
}

// Do-While Loop (Executes block first, then evaluates condition!)
int choice;
do {
    System.out.println("Processing transaction...");
    choice = 0;
} while (choice != 0);

Module 4: For Loop & Enhanced For-Each Loop

Concept: Definite Iteration. Use a standard index for loop when you know the exact iteration count or need to track element indices. Use an Enhanced For-Each Loop for clean, readable traversal over arrays or collections.

// Standard Index-Based For Loop
for (int i = 0; i < 5; i++) {

// Enhanced For-Each Loop (Clean traversal!)
String[] names = {"Alice", "Bob", "Charlie"};

Module 5: Dynamic Arrays (ArrayList & Wrapper Classes)

Concept: Resizable Lists. Standard Java arrays have fixed sizes. When you need a list that dynamically expands as elements are added, use java.util.ArrayList.

1. Wrapper Classes (Primitives vs. Objects)

ArrayList can ONLY store Objects, not primitives! Java provides Wrapper Classes that wrap primitive values into reference objects:

  • int → Integer
  • double → Double
  • boolean → Boolean
  • char → Character
import java.util.ArrayList;
import java.util.Collections;

public class Main {
    public static void main(String[] args) {
        // Create dynamic list storing Integers
        ArrayList list = new ArrayList<>();
        
        // 1. Add elements (.add)
        list.add(45);
        list.add(12);
        list.add(89);
        
        // 2. Get element at index (.get - DO NOT use square brackets [])
        System.out.println("First element: " + list.get(0));
        
        // 3. Count total elements (.size() - DO NOT use .length)
        System.out.println("List size: " + list.size());
        
        // 4. Sort dynamic list using Collections framework
        Collections.sort(list);
        System.out.println("Sorted ArrayList: " + list);
    }
}

Module 6: HashSet & Unique Sets

Concept: Fast Unique Collections. A HashSet stores unique items and enforces no duplicate elements. Because it uses hashing algorithms internally, checking whether an element exists via .contains() takes ultra-fast $O(1)$ constant time!

import java.util.HashSet;

public class Main {
    public static void main(String[] args) {
        HashSet set = new HashSet<>();
        
        set.add("Apple");
        set.add("Banana");
        set.add("Apple");  // Duplicate automatically rejected!
        
        System.out.println("Unique count: " + set.size());  // Output: 2
        
        // Instant O(1) Search
        if (set.contains("Apple")) {
            System.out.println("Apple is in the set!");
        }
    }
}

Java Level 3: OOP & Advanced Algorithms

Module 1: Classes & Objects (OOP Fundamentals)

Concept: Blueprint for Real-World Objects. Object-Oriented Programming (OOP) allows us to build custom data types. A Class is a blueprint, and an Object is an instance built from that blueprint.

class Student {
    String name;
    int score;

    // Constructor: Method called when creating a new Student instance
    public Student(String name, int score) {
        this.name = name;
        this.score = score;
    }
}

public class Main {
    public static void main(String[] args) {
        Student s1 = new Student("Alice", 95);
        System.out.println(s1.name + ": " + s1.score);

Module 2: HashMap (Key-Value Mapping)

Concept: Custom Key Lookups. A HashMap maps unique Keys to Values (e.g., Student Name → Grade), providing instant $O(1)$ lookups and updates.

import java.util.HashMap;

public class Main {
    public static void main(String[] args) {
        HashMap map = new HashMap<>();
        
        map.put("Alice", 90);
        map.put("Bob", 85);

        System.out.println("Alice's Score: " + map.get("Alice")); // Output: 90
        
        // .getOrDefault provides a fallback value if the key does not exist!
        System.out.println("Charlie's Score: " + map.getOrDefault("Charlie", 0)); // Output: 0
    }
}

Module 3: 2D Arrays & Grid Traversal

Concept: Matrix Grids. Represent grids and tables using 2D arrays int[][] grid = new int[rows][cols];. Always use nested index loops r and c for precise grid coordinate control.

public class Main {
    public static void main(String[] args) {
        int rows = 3, cols = 3;
        int[][] grid = new int[rows][cols];
        
        grid[0][0] = 1;  // Row 0, Col 0

        // Preferred Nested Index Loop Traversal
        for (int r = 0; r < grid.length; r++) {
            for (int c = 0; c < grid[0].length; c++) {
                System.out.print(grid[r][c] + " ");
            }
            System.out.println();
        }
    }
}

Module 4: Fast I/O (BufferedReader & StringTokenizer)

Performance Optimization: Standard Scanner is too slow for parsing large inputs ($N > 10^5$) within CCC 2-second time limits. Competitive Java programmers use BufferedReader and StringTokenizer for ultra-fast performance!

import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        
        int a = Integer.parseInt(st.nextToken());
        int b = Integer.parseInt(st.nextToken());
        
        System.out.println(a + b);
    }
}

Module 5: Prefix Sum Arrays

Concept: $O(1)$ Range Sum Queries. Precalculate cumulative totals in a prefix array prefix[i + 1] = prefix[i] + arr[i] to answer any range sum query from $L$ to $R$ instantly via prefix[R + 1] - prefix[L].

int[] arr = {1, 2, 3, 4, 5};
int[] prefix = new int[arr.length + 1];

for (int i = 0; i < arr.length; i++) {
    prefix[i + 1] = prefix[i] + arr[i];
}

// Sum from index L=1 to R=3 (values: 2 + 3 + 4 = 9)
int L = 1, R = 3;
int rangeSum = prefix[R + 1] - prefix[L];
System.out.println("Range Sum: " + rangeSum);  // Output: 9

Module 6: Stack, Queue & PriorityQueue

Concept: Linear & Heap Data Structures.

  • Stack (LIFO): Last In, First Out (Use ArrayDeque).
  • Queue (FIFO): First In, First Out (Use ArrayDeque).
  • PriorityQueue (Heap): Pops smallest (or largest) element first in $O(\log N)$ time.
import java.util.*;

public class Main {
    public static void main(String[] args) {
        // Stack (LIFO)
        ArrayDeque stack = new ArrayDeque<>();
        stack.push(10);
        int top = stack.pop();

        // Queue (FIFO)
        ArrayDeque queue = new ArrayDeque<>();
        queue.offer(10);
        int front = queue.poll();

        // Min-Heap PriorityQueue
        PriorityQueue pq = new PriorityQueue<>();
        pq.offer(30);
        pq.offer(10);
        System.out.println(pq.poll()); // Output: 10 (Smallest element pops first!)
    }
}

Module 8: Recursion & DFS

Concept: Deep Exploration. Depth-First Search goes as deep as possible down a path before backtracking, naturally implemented using recursion.

public static void dfs(int r, int c, int[][] grid, boolean[][] visited) {
    if (r < 0 || r >= grid.length || c < 0 || c >= grid[0].length) return;
    if (visited[r][c] || grid[r][c] == 1) return;

    visited[r][c] = true;

    dfs(r + 1, c, grid, visited);
    dfs(r - 1, c, grid, visited);
    dfs(r, c + 1, grid, visited);
    dfs(r, c - 1, grid, visited);
}
