Java Level 1: Foundations

Module 1: Main Method & Standard Output

Concept: Java is a strictly object-oriented, statically typed language. Every program must exist inside a class container, and execution starts strictly at the main entry method.

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World");
        System.out.println("Welcome to Java Programming!");
    }
}
📌 Online Judge Requirement (DMOJ/USACO): In competitive programming platforms, your main class name must be named Main when submitted as a single file.

Understanding Escape Characters (\n, \t) & Print Options

System.out.println() automatically advances the cursor to a new line, whereas System.out.print() keeps output on the same line. You can format formatting using escape sequences:

System.out.print("Item\tQty\tPrice\n");
System.out.print("---------------------\n");
System.out.print("Book\t1\t$15.00\n");

Module 2: Primitive Types & Basic Math

Concept: Java stores values directly in stack memory using primitive types. Integers default to int (32-bit), decimals default to double (64-bit), and long integers require an L suffix.

Data Type Bit Size Value Range / Example
int32-bit$-2^{31}$ to $2^{31}-1$ (approx $\pm 2.14 \times 10^9$)
long64-bit$-2^{63}$ to $2^{63}-1$ (e.g., 10000000000L)
double64-bit64-bit IEEE 754 float (e.g., 3.14159)
boolean1-bittrue or false
 
int a = 10;
int b = 3;
System.out.println(a / b);        // Output: 3 (Integer division truncates)
System.out.println((double) a / b); // Output: 3.3333333333333335
💡 Integer Overflow Warning: Multiplying two large integers (e.g., $10^6 \times 10^6$) before assigning to a long will overflow unless explicitly cast: long result = (long) a * b;

Using java.lang.Math

double radius = 5.0;
double area = Math.PI * Math.pow(radius, 2);
double root = Math.sqrt(16.0);
System.out.println("Area: " + area + ", Sqrt: " + root);

Module 3: String Operations

Concept: In Java, String is an immutable reference object stored in heap memory. Modifying a string creates a completely new string reference.

String str = "Java Programming";

System.out.println(str.length());        // Output: 16
System.out.println(str.charAt(0));       // Output: 'J'
System.out.println(str.substring(0, 4)); // Output: "Java" (End index excluded!)
🚨 Value Equality Warning: Never compare String contents using == (which compares memory addresses)! Always use str1.equals(str2) or str1.equalsIgnoreCase(str2).

Module 4: Scanner Input & If-Else

Concept: The Scanner class (from java.util) parses standard console input tokens. Branching logic uses if, else if, and else blocks.

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("Enter score: ");
        int score = scanner.nextInt();
        scanner.nextLine(); // Clear leftover newline buffer!
        
        if (score >= 90) {
            System.out.println("Grade: A");
        } else if (score >= 60) {
            System.out.println("Pass");
        } else {
            System.out.println("Fail");
        }
        
        scanner.close();
    }
}
💡 The Scanner Trap: Calling nextInt() or nextDouble() leaves a trailing \n in the input buffer. Always execute a dummy scanner.nextLine(); before reading subsequent string input lines!

Module 6: Methods & Scope

Concept: Methods promote code reuse and abstraction. Java parameters are strictly **Pass-by-Value** (primitive copies vs. object reference address copies).

public class Main {
    public static boolean isEven(int n) {
        return n % 2 == 0;
    }

    public static void main(String[] args) {
        System.out.println(isEven(4)); // true
    }
}

Module 1: Classes & Objects (Encapsulation & Comparable)

Concept: Encapsulate fields with private access modifiers, build robust constructors, and implement Comparable<T> for custom object sorting.

class Student implements Comparable {
    private String name;
    private int score;

    public Student(String name, int score) {
        this.name = name;
        this.score = score;
    }

    @Override
    public int compareTo(Student other) {
        return Integer.compare(other.score, this.score); // Descending score sort
    }
}

Module 2: HashMap (Key-Value Tables)

Concept: Store unique keys mapped to values with average $O(1)$ search and insertion performance backed by hash buckets.

import java.util.HashMap;

HashMap freq = new HashMap<>();

Module 4: Fast I/O (BufferedReader & PrintWriter)

Concept: Standard Scanner causes Time Limit Exceeded (TLE) on huge contest inputs. Upgrade to buffered character streams for high performance.

import java.io.*;
import java.util.StringTokenizer;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader reader = new BufferedReader(new InputStreamReader(System.in));
        PrintWriter out = new PrintWriter(new BufferedOutputStream(System.out));
        
        StringTokenizer st = new StringTokenizer(reader.readLine());
        int n = Integer.parseInt(st.nextToken());
        
        out.println("Processed: " + n);
        out.flush(); // ALWAYS flush output buffer!
        out.close();
    }
}

Module 5: Prefix Sum Arrays

Concept: Precompute cumulative totals in $O(N)$ time to answer any range sum query between $L$ and $R$ in constant $O(1)$ time: $\text{Sum}(L, R) = P[R] - P[L - 1]$.

int[] arr = {3, 7, 2, 5, 8};
long[] pref = new long[arr.length + 1];

for (int i = 1; i <= arr.length; i++) {
    pref[i] = pref[i - 1] + arr[i - 1];
}

// 1-indexed range sum query L=2, R=4
long rangeSum = pref[4] - pref[1];

Module 8: Recursion & DFS (Depth-First Search)

Concept: Deep path exploration using recursive call stack execution and backtracking.

public static void dfs(int r, int c, int[][] grid, boolean[][] visited) {
    if (r < 0 || r >= grid.length || c < 0 || c >= grid[0].length) return;
    if (grid[r][c] == 0 || visited[r][c]) return;

    visited[r][c] = true; // Mark visited

    dfs(r - 1, c, grid, visited); // Up
    dfs(r + 1, c, grid, visited); // Down
    dfs(r, c - 1, grid, visited); // Left
    dfs(r, c + 1, grid, visited); // Right
}
