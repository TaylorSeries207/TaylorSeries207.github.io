C++ Level 1: Foundations

Module 1: Headers & std::cout

Why C++ is the Gold Standard for Competitions: C++ is the most popular programming language in competitive programming (CCC, IOI, USACO) because of its raw execution speed and granular control over computer memory.

1. Deconstructing C++ Boilerplate Code

Let's dissect the essential template required for every C++ program:

#include    // Header library for Input/Output stream
using namespace std;  // Allows using cout, cin without std:: prefix

int main() {
    // std::cout uses the insertion operator << to stream text
    cout << "Hello, World!" << endl;
    cout << "Welcome to C++ Coding Class!\n";
    
    return 0;  // Returns 0 to tell OS that program executed successfully
}
  • #include <iostream>: Imports the standard Input/Output library containing cout and cin.
  • using namespace std;: Brings the Standard Namespace into global scope so you can type cout instead of std::cout.
  • int main() { ... }: The mandatory execution entry point of every C++ program.
  • cout <<: Streams data out to the console terminal screen.
  • endl vs "\n": Both create a new line, but endl forces an extra buffer flush. In competitive programming, always prefer "\n" for maximum execution speed!

Module 2: Variables & Arithmetic Operations

Concept: Static Typing. Like Java, C++ requires explicit type declarations for all variables. This allows the compiler to convert your code directly into super-fast native machine CPU code!

1. Core C++ Primitive Types

Data Type Description Range / Note
int 32-bit Integer $-2 \times 10^9$ to $+2 \times 10^9$
long long 64-bit Big Integer Up to $\approx 9 \times 10^{18}$. Essential for CCC Senior!
double 64-bit Floating Decimal High precision decimal numbers
bool Boolean true (1) or false (0)
char Single Character Enclosed in single quotes (e.g., 'A') 
#include 
using namespace std;

int main() {
    int a = 10;
    int b = 3;
    
    // 🚨 INTEGER DIVISION: Drops decimal digits completely!
    cout << a / b << "\n";          // Output: 3
    
    // ✅ FIX: Typecast one operand to double
    cout << (double)a / b << "\n";  // Output: 3.33333
    
    // Modulus (Remainder)
    cout << a % b << "\n";          // Output: 1
    
    return 0;
}

Module 3: std::string & Character Operations

Concept: In C++, std::string is a dynamic sequence of characters provided by #include <string>. Unlike Java, C++ strings are mutable (can be modified in-place) and can be compared directly using standard ==!

#include 
#include 
using namespace std;

int main() {
    string msg = "Hello C++!";
    
    // 1. Length of string
    cout << msg.length() << "\n";        // Output: 10
    
    // 2. Direct Index Access (Zero-based indexing!)
    cout << msg[0] << "\n";               // Output: 'H'
    
    // 3. Modifying String In-Place (C++ Unique Feature!)
    msg[0] = 'Y';
    cout << msg << "\n";                  // Output: "Yello C++!"
    
    // 4. Content Comparison (In C++, == checks actual string content!)
    string s1 = "cat", s2 = "cat";
    if (s1 == s2) {
        cout << "Strings match!\n";       // ✅ Valid and recommended in C++!
    }
    
    return 0;
}

Module 4: std::cin Input & Conditional Logic

Reading Console Input: We use cin >> (extraction operator) to read input values into variables from the console.

#include 
using namespace std;

int main() {
    int mark;
    cout << "Enter exam mark: ";
    cin >> mark;  // Reads integer input
    
    // Conditional Branching
    if (mark >= 90) {
        cout << "Grade: A+\n";
    } else if (mark >= 80) {
        cout << "Grade: A\n";
    } else if (mark >= 50) {
        cout << "Grade: Pass\n";
    } else {
        cout << "Needs Review!\n";
    }
    
    return 0;
}
⚠️ cin Trailing Newline Issue:
Using cin >> var leaves leftover \n in the buffer. If you plan to call getline(cin, str) right after, use cin.ignore(); to clear the trailing newline first!

Module 6: Functions & Pass-by-Value

Functions allow you to break down complex algorithms into clean, reusable modular components.

#include 
using namespace std;

// Custom function definition
int calculateArea(int width, int height) {
    return width * height;
}

int main() {
    int area = calculateArea(10, 20);

🔒 Pass-by-Value Default:
By default, C++ creates a copy of arguments passed into functions. Modifying parameter values inside the function will NOT alter the original variable in main().

Module 5: Dynamic Arrays (std::vector)

Concept: Dynamic Resizable Arrays. std::vector is the most versatile standard template library (STL) container in C++. It automatically resizes itself dynamically when new elements are added!

#include 
#include 
#include 
using namespace std;

int main() {
    vector vec;  // Declare dynamic vector of integers
    
    // 1. Append elements to back in O(1) time
    vec.push_back(45);
    vec.push_back(12);
    vec.push_back(89);
    
    // 2. Access elements using square brackets []
    cout << "First item: " << vec[0] << "\n";
    
    // 3. Size of vector
    cout << "Total items: " << vec.size() << "\n";
    
    // 4. Sort vector using STL sort: sort(vec.begin(), vec.end())
    sort(vec.begin(), vec.end());
    
    for (int x : vec) {
        cout << x << " ";  // Output: 12 45 89
    }
    cout << "\n";
    
    return 0;
}

C++ Level 3: STL Containers & Algorithms

Module 1: Pass-by-Reference (&)

CRITICAL PERFORMANCE RULE: Passing large data structures (like vector or string) into functions without an ampersand & causes C++ to make a full deep copy, taking slow $O(N)$ time and causing TLE! Always use Pass-by-Reference (&)!

#include 
#include 
using namespace std;

// ✅ Fast O(1) Pass-by-Reference! Modifies original vector directly!
void processVector(vector &vec) {
    vec[0] = 999;
}

int main() {
    vector nums = {1, 2, 3};
    processVector(nums);
    cout << nums[0] << "\n";  // Output: 999
    return 0;
}

Module 2: std::unordered_map & std::map

Hash Maps vs. Red-Black Tree Maps:

  • std::unordered_map: $O(1)$ Hash Table (Unordered). Recommended for speed.
  • std::map: $O(\log N)$ Self-Balancing Red-Black BST (Keeps keys strictly sorted!).
#include 
#include 
using namespace std;

int main() {
    unordered_map scores;
    scores["Alice"] = 90;
    scores["Bob"] = 85;

    cout << "Alice's score: " << scores["Alice"] << "\n";
    return 0;
}

Module 4: Fast I/O Optimization

The 2-Line C++ Performance Booster: By default, C++ syncs cin/cout with C's stdio stream, making standard input slow. Add these two lines at the start of main() to unlock maximum speed!

#include 
using namespace std;

int main() {
    // ⚡ UNLOCK MAXIMUM FAST I/O SPEED
    ios::sync_with_stdio(0);
    cin.tie(0);
    
    int n;
    cin >> n;
    cout << n << "\n";
    
    return 0;
}

Module 8: Recursion & DFS

void dfs(int r, int c, vector>& grid, vector>& visited) {
    int rows = grid.size(), cols = grid[0].size();
    if (r < 0 || r >= rows || c < 0 || c >= cols) return;
    if (visited[r][c] || grid[r][c] == 1) return;

    visited[r][c] = true;

    dfs(r + 1, c, grid, visited);
    dfs(r - 1, c, grid, visited);
    dfs(r, c + 1, grid, visited);
    dfs(r, c - 1, grid, visited);
}
